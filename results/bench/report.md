## Practicality summary

**Score:** `interactive_local`

- Text decode ~200.0 tok/s → snappy interactive QA.
- Best text TTFT 42 ms → feels interactive.
- Multimodal top-3 e2e is ~1.21× text (440 ms vs 365 ms) — expect vision cost on each call.
- On 5-page bucket, raising top-k 1→3 changes text e2e by ~1.01× (prefill grows with evidence).
- Peak RSS ~207 MB fits typical 16GB laptops alongside OCR/index.
- No VRAM reported (CPU build or pynvml missing) — CPU path is valid but slower.

**Recommendation:** Keep retrieval top-k small (1–3), max_tokens≤128 for interactive use, and use gemma-3-4b-it-qat-q4_0 Q4_0 so text+vision share a ~3–4GB weight budget on a local machine.
